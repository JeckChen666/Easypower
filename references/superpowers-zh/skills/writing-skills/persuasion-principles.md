# Skill 设计中的说服原则

## 概述

LLM 对说服原则的响应方式与人类相似。理解这些心理机制可以帮助设计更有效的 skill。目的不是操纵，而是确保关键实践在压力下仍被遵守。

**研究基础：**Meincke 等人在 2025 年对 28,000 次 AI 对话测试了 7 种说服原则；使用这些技术后，遵从率从 33% 提升到 72%（p < .001）。

## 七种原则

### 1. 权威

**含义：**对专业知识、资历或官方来源的服从。

**在 skill 中的用法：**使用命令式语言（“必须”“永远不要”）、不可协商的表述（“没有例外”），减少决策疲劳和自我合理化。

**适用：**纪律类 skill（TDD、验证）、安全关键实践和已确定的最佳实践。

```markdown
✅ 先写代码再写测试？删除代码，重新开始，没有例外。
❌ 条件允许时可以考虑先写测试。
```

### 2. 承诺

**含义：**保持与先前行动、陈述或公开声明一致。

**在 skill 中的用法：**要求宣布正在使用的 skill，强制在选项中做明确选择，用待办清单跟踪多步骤工作。

**适用：**确保流程真的被执行、约束多步骤过程和建立责任机制。

```markdown
✅ 找到 skill 后必须宣布：“我正在使用 [Skill Name]”。
❌ 可以考虑告诉协作者你正在使用什么 skill。
```

### 3. 稀缺性

**含义：**时间限制或资源有限带来的紧迫感。

**在 skill 中的用法：**设置“继续前”“完成后立即”等时限和顺序依赖，防止拖延到以后。

**适用：**即时验证、时间敏感流程和防止“稍后再做”。

```markdown
✅ 完成任务后立即请求代码评审，再进入下一步。
❌ 方便时再评审代码即可。
```

### 4. 社会证明

**含义：**遵循他人的做法或被视为正常的做法。

**在 skill 中的用法：**使用“每次”“始终”等普遍模式，明确“没有 X 就是失败”的模式，建立规范。

```markdown
✅ 没有待办跟踪的清单一定会漏步骤。
❌ 有些人觉得待办清单对清单任务有帮助。
```

### 5. 共同体

**含义：**共享身份和“我们”的归属感。

**在 skill 中的用法：**使用“我们的代码库”“我们一起工作”等协作语言，强调共同目标。

**适用：**协作流程、团队文化和非层级式实践。

```markdown
✅ 我们是一起工作的同事，我需要你诚实的技术判断。
❌ 如果我错了，你应该告诉我。
```

### 6. 互惠

**含义：**人们感到需要回报已经获得的好处。

在 skill 中应谨慎使用，因为容易显得操纵；几乎总有其他更合适的原则。

### 7. 喜爱

**含义：**更愿意配合自己喜欢的人。

不要用它来强制遵从。它会损害诚实反馈文化并造成迎合。纪律约束中始终避免使用。

## 按 skill 类型组合

| Skill 类型 | 使用 | 避免 |
|---|---|---|
| 纪律约束 | 权威 + 承诺 + 社会证明 | 喜爱、互惠 |
| 指导/技术 | 适度权威 + 共同体 | 过重的权威 |
| 协作 | 共同体 + 承诺 | 权威、喜爱 |
| 参考资料 | 只保持清晰 | 全部说服原则 |

## 为什么有效

**清晰边界的规则减少合理化：**“必须”消除决策疲劳，绝对措辞减少“这算例外吗”的疑问，明确反合理化条款能堵住常见漏洞。

**实施意图形成自动行为：**清晰触发条件加上必需动作，比“通常应该”更容易执行，并降低认知负担。

**LLM 具有类人行为：**训练文本包含这些模式；权威语言常先于遵从出现，承诺序列和社会证明模式会建立规范。

## 合理使用

**正当用途：**确保关键实践被遵守、编写有效文档、预防可预测失败。

**不当用途：**为个人利益操纵、制造虚假紧迫感、使用羞愧感强迫遵从。

**判断标准：**如果用户完全理解这项技术，它是否仍然服务于用户真实利益？

## 研究引用

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business。

**Meincke, L. 等 (2025).** *Call Me A Jerk: Persuading AI to Comply with Objectionable Requests.* University of Pennsylvania。测试了 28,000 次 LLM 对话，遵从率从 33% 提升至 72%，权威、承诺和稀缺性最有效。

## 快速参考

设计 skill 时询问：

1. 它属于哪种类型：纪律、指导还是参考？
2. 想改变什么行为？
3. 哪些原则适用？纪律类通常是权威 + 承诺。
4. 是否组合过多？不要把七种全部用上。
5. 是否合乎伦理，确实服务用户真实利益？
