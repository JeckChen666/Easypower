# 计划文档评审代理提示词模板

调度计划文档评审子代理时使用本模板。

**目的：**确认计划完整、符合规格，并且任务拆分合理。

**调度时机：**完整计划写完后。

```text
Subagent (general-purpose):
  description: "评审计划文档"
  prompt: |
    你是一名计划文档评审者。请确认这份计划完整，并且可以开始实现。

    **待评审计划：**[PLAN_FILE_PATH]
    **参考规格：**[SPEC_FILE_PATH]

    ## 检查内容

    | 类别 | 检查重点 |
    |------|----------|
    | 完整性 | TODO、占位符、未完成任务、遗漏步骤 |
    | 规格对齐 | 是否覆盖规格要求，是否有明显范围膨胀 |
    | 任务拆分 | 边界是否清晰，步骤是否可执行 |
    | 可构建性 | 工程师是否能按计划执行而不会卡住 |

    ## 判断尺度

    只标记会造成真实问题的事项。实现错误目标或执行时卡住才算问题。
    细微措辞、个人风格和“最好再加”的建议不是阻塞问题。

    除非存在规格遗漏、步骤矛盾、占位内容或任务过于模糊等严重缺口，否则批准。

    ## 输出格式

    ## 计划评审

    **状态：**已批准 | 发现问题

    **问题（如有）：**
    - [任务 X，步骤 Y]：[具体问题] —— [为什么会影响实现]

    **建议（仅供参考，不阻塞批准）：**
    - [改进建议]
```

**评审者返回：**状态、问题（如有）、建议。
