# Superpowers 中文译版参考

本目录保存 Easypower 仓库早期对 Superpowers Skills 的中文翻译。

这些文件用于：

- 对比 Superpowers 的触发条件和流程门禁；
- 研究其中的调试、执行、评审和验证机制；
- 为后续 Easypower Skill 提供设计素材；
- 追踪哪些能力已经重新设计，哪些仍待处理。

这些文件不属于 Easypower 正式 Skill，不应被安装、发布或参与自动 Skill 发现。正式 Skill 只存在于仓库根目录的 `skills/`。

迁移原则是吸收机制而不是逐文件改写：先明确实际业务问题和失败场景，再决定是否需要创建独立 Easypower Skill。原译版中的广泛自动触发、强制 TDD、固定多阶段评审和全流程门禁不自动继承。
