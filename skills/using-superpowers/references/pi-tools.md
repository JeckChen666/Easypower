# Pi 工具映射

Skill 使用“调度子代理”“创建待办”“读取文件”等动作描述；在 Pi 上对应以下工具：

| Skill 请求的动作 | Pi 对应项 |
|---|---|
| 调度子代理（`Subagent (general-purpose):` 模板） | 如已安装 `pi-subagents`，使用其中的 `subagent` 工具。 |
| 任务跟踪（“创建待办”“标记完成”） | 使用已安装的 todo/task 工具；没有时在计划或 `TODO.md` 中维护。 |

## 子代理

Pi 核心不提供标准子代理工具。`pi-subagents` 是可选扩展，支持单代理、链式、并行、异步、分叉上下文和恢复/状态工作流。

没有子代理工具时，不要伪造 `Task` 调用；在当前会话顺序执行，或说明可选能力未安装。

## 任务清单

Pi 核心不提供标准任务清单工具。有扩展时遵循扩展文档；没有时使用 Superpowers 计划文件、Markdown 清单或仓库内 `TODO.md`。旧文档中的 `TodoWrite` 应理解为上述任务跟踪动作。
