# 逻辑与状态原型

适用于公式口径、数据形状、状态机和操作顺序需要通过具体案例才能判断的情况。

## 结构

将待判断逻辑放在小型纯函数、Reducer（状态归约函数）或状态机中，外层使用最薄的 CLI（命令行界面）、单页 HTML 或现有调试入口驱动。界面不是重点，但每次操作后应显示完整相关状态、派生结果和与上一状态的差异。

使用代表性业务样本覆盖能区分候选规则的场景。例如跨月退款口径至少展示：同月退款、跨月退款、跨年退款、部分退款、多次退款，以及首次发布和历史重算后的月度结果。

## 边界

- 状态默认只在内存；
- 不访问生产数据库或写入真实外部服务；
- 不为每个规则设计插件或通用引擎；
- 不要求完整测试套件，但必须实际运行判定场景；
- 纯逻辑可以作为决策参考，进入生产前仍需按正式架构重写或严格审查。

## 交付

提供一个运行命令、预置场景、用户可修改的最小输入和并排结果。最后保存被批准的业务口径、典型输入输出和重算/版本语义，供 Spec 和后续业务验证使用。
