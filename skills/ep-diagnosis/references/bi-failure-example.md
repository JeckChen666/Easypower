# BI 报表失败诊断示例

## 症状

业务方 Excel 中“华南区 / 3 月 / 净收入”为 `12,483,920.35`，优化后程序输出 `12,471,920.35`。其他汇总暂未发现异常。

## Feedback Loop（反馈闭环）

固定同一输入、业务口径版本和实现版本，只生成该指标的贡献明细及汇总。反馈同时比较：目标单元格、贡献记录集合和相关守恒关系。不要通过硬编码目标金额让测试通过。

## 缩小与追踪

按组织、月份、规则类型和来源单据对新旧结果做集合差异，找到造成 `12,000.00` 差额的记录。沿输入解析、地区归属、月份口径、资格过滤、调整项、聚合和舍入逐段比较，定位首次偏差。

可能发现优化后的分区裁剪错误地排除了月末冲销记录。查询少一条记录是直接原因；错误的月份上界才是根因。

## 修复与证据

在计算模块的稳定业务接口保留最小样本，覆盖月末冲销和半开时间区间。修复边界后验证：

- 与原 Excel 中的基准单元格一致；
- 差异记录集合为空；
- 华南月度和全国总量守恒；
- 代表性性能基准仍满足已批准预算。

无需为这个局部边界错误固定运行所有 UI 测试。若月份口径在 Spec 中存在两种合理解释，停止修复并让业务方批准口径。
