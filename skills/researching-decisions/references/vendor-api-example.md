# 供应商 API 研究示例

## 调研范围

调查支付供应商的请求幂等、批量查询和退款重试。必须先固定供应商、产品/API、版本、商户与交易地区、账户类型和 sandbox/production 环境。

## 事实问题

- 幂等适用端点、键作用域、有效期、相同键不同请求体、并发和超时重放；
- 批量查询的定义、单批上限、分页、限流、一致性延迟和部分失败；
- 退款是供应商自动重试还是商户安全重提，可重试错误、稳定退款 ID、最终状态查询和 webhook 对账。
