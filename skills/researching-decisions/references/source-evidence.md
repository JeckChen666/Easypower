# 来源与证据等级

## 来源层级

| 等级 | 来源 | 用途 |
|---|---|---|
| E1 | 正式规范、法规、官方 API 参考、版本化迁移指南 | 公共契约和明确限制 |
| E2 | 官方 release notes、能力矩阵、第一方包元数据和源代码 | 版本行为与实现事实 |
| E3 | 第一方支持书面答复、sandbox 或可复现实验 | 文档空白和运行行为 |
| E4 | 项目锁文件、配置、代码、日志和部署清单 | 当前项目适用性 |
| E5 | 社区 issue、博客、问答和搜索摘要 | 发现线索，不单独支撑结论 |

等级不是绝对排序。法规解释、公共契约和运行实现需要不同来源；关键是来源是否拥有该事实，并精确匹配产品、版本、地区和环境。

## 原子证据格式

```markdown
### F-01 <事实标题>
**类型：** 官方事实 | 项目事实 | 实验观察
**结论：**
**原文/位置：**
**来源：** <URL 或文件路径>
**发布者：**
**版本/日期：**
**访问日期：**
**适用范围：**
**限制：**
```

对网页优先引用稳定锚点、章节或版本页；对源码引用仓库、tag/commit 和文件行；对 API 响应记录请求条件、账户和环境。

## 证据强度

- **Confirmed**：一手来源明确且范围匹配；
- **Conditional**：事实成立，但结论依赖已声明前提；
- **Observed**：只在指定实验环境观察到；
- **Unknown**：证据缺失、冲突或范围不匹配。

禁止把 Observed 外推成所有地区/账户的供应商承诺。
