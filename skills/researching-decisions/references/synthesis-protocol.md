# 研究合成协议

## 分层台账

| ID | 类型 | 主张 | 依据 | 强度 |
|---|---|---|---|---|
| F-01 | 官方事实 | ... | E1 | Confirmed |
| P-01 | 项目事实 | ... | E4 | Confirmed |
| I-01 | 推论 | 基于 F-01 + P-01 ... | ... | Conditional |
| R-01 | 建议 | 在 I-01 前提下 ... | ... | Conditional |
| U-01 | 未知 | ... | 缺少 ... | Unknown |

推论必须引用其事实 ID。建议必须说明哪些新证据会推翻或改变它。

## 决策摘要

```markdown
## 直接回答
<支持 / 条件支持 / 不支持 / 未知，以及适用范围>

## 决策影响
- Spec：
- 架构：
- Plan/验证：

## 尚需确认
- <U-xx 和下一步>

## 重新核验触发
- <版本、地区、账户、法规或日期变化>
```

不要把所有阅读笔记搬进结论。保留能支撑决策的最少事实、冲突和未知项。

## 并行研究合并

协调 Agent 统一 ID、去重相同事实、检查各代理使用的研究坐标，并亲自核验关键引用。相互矛盾的代理结论不能取多数票；回到原始来源和适用范围解决。
